# Development material

Technical investigation and future test evidence belong in this directory.
The manifest remains at the project root. Runtime modules use LMS's required
`lib/Plugins/ShazamCapture/` namespace path.

- `TECHNICAL-NOTE.md` documents the capture boundary, UI integration, permanent
  recognition history, and external-link normalization.
- `TESTING.md` contains terminal-safe verification and manual UI acceptance
  checks.
- `CHANGELOG.md` records implemented behavior and rejected approaches.
- `UPGRADE-TROUBLESHOOTING.md` records Docker upgrade checks, LMS template and
  string-cache behavior, and the confirmed recovery command.
